# 为什么中文 · Wèi Shénme Zhōngwén

เว็บเรียนภาษาจีนสำหรับคนไทย — คอร์สพินอิน · ข้อสอบจำลอง HSK (100 ข้อ × 5 ชุด) · เกมภาษาแบบด่าน · เขียนอักษรจีนพร้อมลำดับขีด · บทความสั้น · ระบบสมาชิก + พรีเมียม

เปิดใช้งานได้ทันทีโดยดับเบิลคลิก **`index.html`** (ไม่ต้องติดตั้งเซิร์ฟเวอร์ ไม่ต้องต่ออินเทอร์เน็ต — ยกเว้นฟอนต์ Google Fonts และรูป QR ที่จะโหลดเมื่อออนไลน์)

> **อัปเกรดล่าสุด (v2026.3):** เมนูบนเหลือ 8 รายการ — พินอินย้ายเข้ารวมในหน้า "เริ่มเรียน" (แท็บ) · บล็อกย้ายเข้ารวมในหน้า "บทความ" (แท็บ) · อักษรจีนรวมลำดับขีด+พื้นฐานขีด · HSK รวมคำศัพท์+ข้อสอบจำลอง (100 ข้อ × 5 ชุด ชุดแรกฟรี) · เส้นทางการเรียน Roadmap พร้อมติดตามพัฒนาการ · ไอคอนเป็นไฟล์ SVG จริง (sprite + 139 ไฟล์)

## ฟีเจอร์ใหม่ล่าสุด

### 🧩 ส่วนประกอบอักษร (部首) + เกมประกอบอักษร
- แท็บ **"ส่วนประกอบอักษร & เกมประกอบ"** ในหน้าอักษรจีน (แสดงเฉพาะแท็บนี้ ไม่ปนกับแท็บอื่น): คลังส่วนประกอบ 31 ตัว **แบ่ง 5 หมวดหมู่** (คนและชีวิต · ธรรมชาติ · สิ่งของและสังคม · สัตว์ · อื่น ๆ) พร้อมชื่อ ความหมาย และตัวอย่าง — **คลิกส่วนประกอบเพื่อดูอักษรทุกตัวที่ใช้มัน** (ดึงพินอิน/ความหมายจากฐานข้อมูล 3,000 ตัว + คู่ประกอบในคลัง)
- **เกมโต้ตอบ 5 เกม รูปแบบตัวใหญ่ชัดเจน**: สร้างอักษรจากส่วนประกอบ · สร้างคำจากอักษร · ประกอบพินอิน (พยัญชนะ+สระ+วรรณยุกต์) · เลือกคู่ส่วนประกอบ · แยกอักษรเป็นส่วนประกอบ — ลากวางหรือแตะสลับได้ พร้อมคะแนน สตรีค และปุ่มดูวิธีเขียน

### 💬 บทสนทนา (对话) + 📜 ประวัติศาสตร์จีน
- หน้า Articles มีแท็บใหม่ **บทสนทนา**: ตัวละครต้นฉบับ (小明 小李 王老师 安娜 张阿姨 — SVG วาดเอง) 12 บท 6 หมวด (ทั่วไป/การเรียน/การงาน/เทคโนโลยี/ประเทศจีน/ท่องเที่ยว) บทละ 4+ ผลัด · **สลับพินอิน เปิด/ปิด** · สรุปคำศัพท์ใหม่พร้อมระดับ HSK · ฟังเสียงอ่านสองเสียง
- แท็บ **ประวัติศาสตร์**: เส้นเวลา 18 ราชวงศ์เซี่ย→ชิง — คลิกเพื่อดูช่วงเวลา ผู้สถาปนา เหตุการณ์สำคัญ ความรุ่งเรือง พร้อม**ภาพจักรพรรดิ SVG ต้นฉบับ**ตามเครื่องทรงจริง (秦漢 玄色冕服 · 唐宋 赭黄+幞头 · 明 แดง+乌纱折角巾 · 清 เหลือง+朝珠) อ้างอิง [中国历代纪元表](https://wapbaike.baidu.com/item/%E4%B8%AD%E5%9B%BD%E5%8E%86%E4%BB%A3%E7%BA%AA%E5%85%83%E8%A1%A8/5898503) และ [เครื่องทรงจักรพรรดิ](https://mkan.china.com/article/897719.html)
- **บทความใหม่ 21 เรื่อง** (นิทาน/寓言 8 · ตำนานความเชื่อ 5 · แฟนตาซี 4 · วัฒนธรรม/ชีวิต/เทคโนโลยี/ท่องเที่ยว) ทุกเรื่อง ≥100 ตัวอักษร พินอินสร้างอัตโนมัติจากคลัง HSK

### 📷 สแกนอักษรจีน (OCR) — พรีเมียม (ทดลองฟรี 3 ครั้ง)
- สิทธิ์การสแกน: **ทดลองใช้ฟรี 3 ครั้ง** · แพ็กเกจรายเดือน **20 สแกน/เดือน** · แพ็กเกจ 6 เดือน/ตลอดชีพ **สแกนไม่จำกัด**
- PDF ฝึกเขียนความละเอียด 2 เท่า (192 DPI) 1 ตัวอักษรต่อ 1 หน้า 72 ช่อง 米字格 ต่อตัวอักษร

### 🎓 สมัครสมาชิกพร้อมแผนการเรียน AI
- ฟอร์มสมัครเก็บข้อมูลเป้าหมาย: **เป้าหมายการเรียน** (11 ตัวเลือก) · **ระดับ HSK ปัจจุบัน** · **เมืองในจีนที่อยากไป** · **กรอบเวลาเตรียมสอบ**
- ระบบ AI (rule-based) วิเคราะห์ข้อมูล → แนะนำระดับ HSK เป้าหมาย + **แผนการเรียนรายสัปดาห์** เชื่อมทุกโมดูลของเว็บ (พินอิน/ศัพท์/เขียน/ข้อสอบ) พร้อมเช็กลิสต์ติดตามความคืบหน้าในโปรไฟล์ และแบนเนอร์แผนบนหน้าแรก

### 📝 ข้อสอบ HSK — บทสนทนา + บทอ่านยาว
- ส่วนการฟังมี **บทสนทนา (对话)** เสียงผู้หญิง/ผู้ชายแยกชัดเจน (ต่างทั้งเสียงและระดับ pitch) — **นำหน้าทุกประโยคด้วย "女说。"/"男说。"** (รู้ทันทีว่าใครพูด ไม่มีบทนำยืดเยื้อ) และ**คำถามเป็นภาษาจีนล้วน** (อ่านให้ฟังต่อท้าย ไม่แสดงคำแปลไทย ตามรูปแบบข้อสอบจริง) — ปุ่มฟังเล่นซ้ำได้ไม่จำกัด แสดง/ซ่อนบทสนทนาได้
- ส่วนการอ่าน (HSK 3–6) มี **บทอ่านยาว 50–100+ ตัวอักษร** เรื่องประวัติศาสตร์/วัฒนธรรมจีน (กำแพงเมืองจีน ตรุษจีน เส้นทางสายไหม ขงจื๊อ งิ้วปักกิ่ง กำเนิดอักษรจีน ฯลฯ) พร้อมคำถามย่อย
- ทุกชุดข้อสอบการันตีมีบทสนทนาและบทอ่านยาวทุกครั้ง
- **AI ช่วยทำข้อสอบ (แพ็กเกจ 6 เดือนขึ้นไป)** — หน้าสแกนแยกเป็น **2 โหมดชัดเจน**: โหมดเรียนอักษร (พินอิน/ความหมาย/PDF) และโหมดข้อสอบ — สแกนโจทย์พร้อมตัวเลือกแล้ว **AI ออนไลน์ (LLM)** วิเคราะห์คำตอบพร้อมคำอธิบายภาษาไทยโดยตรง ไม่ต้องตรงกับฐานข้อมูล (ออฟไลน์จึงเทียบคลังข้อสอบ HSK 1–6 ของเว็บเป็นตัวสำรอง)

### 📷 สแกนอักษรจีน (OCR) — จากหน้าแรก
- เข้าจากการ์ด "สแกนอักษรจีน" บนหน้าแรก — ถ่ายรูป (มือถือ) หรืออัปโหลดภาพตัวอักษรจีน
- ระบบอ่านภาพเป็นข้อความด้วย **Tesseract.js** + **ระบบปรับภาพอัตโนมัติ** (ขยายความละเอียด 2400px · grayscale · stretch คอนทราสต์ · retry ด้วยภาพขาว-ดำ Otsu · PSM แยกตามโหมด · รองรับไทย+จีน+อังกฤษ) เพื่อให้อ่านตัวอักษรจีนได้แม่นขึ้น (โหลดโมเดลครั้งแรก — ต้องออนไลน์ครั้งแรก)
- แสดงผลทีละบรรทัด: ตัวอักษร + **พินอิน + ความหมาย + จำนวนขีด** จากฐานข้อมูล 3,000 ตัวอักษร และจับคำศัพท์จากคลัง HSK 6,201 คำ (ตัดคำแบบ longest-match)
- คลิกตัวอักษร → ดูรายละเอียด/ฟังเสียง/ฝึกเขียน · ฟังทั้งบรรทัดได้
- **ส่งออก PDF แบบฝึกเขียน** — **ดาวน์โหลดเป็นไฟล์ PDF ได้โดยตรง** (วาดหน้ากระดาษด้วย canvas + jsPDF — ฟอนต์จริงจากเบราว์เซอร์ เนื้อหาครบทุกหน้า) โดยจัด **1 ตัวอักษรต่อ 1 หน้า** พร้อมช่อง 米字格 72 ช่องต่อตัวอักษร (ช่องแรกเป็นตัวอย่างลายจาง) · มีปุ่มพิมพ์/บันทึกด้วยเบราว์เซอร์สำรอง · ผลสแกนถูกบันทึกข้ามการเปลี่ยนหน้า — กลับมาหน้าสแกนเมื่อไรก็เห็นผลเดิมโดยไม่ต้องสแกนใหม่

### 🔊 เสียงอ่านธรรมชาติขึ้น
- ระบบจัดอันดับเสียงอ่านอัตโนมัติ — เลือกเสียง neural ที่เป็นธรรมชาติที่สุดก่อน (Xiaoxiao/Huihui/Yaoyao/Google 普通话 ฯลฯ) · ความเร็ว 0.78 เพื่อความชัดเจน

### ✨ ดีไซน์ Liquid Glass (Apple-style)
- การ์ด แผง ปุ่ม ช่องกรอก และป็อปอัปทั้งหมดเป็น **กระจกเหลว** — โปร่งแสง + `backdrop-filter` เบลอ + แสงสะท้อนขอบบน (specular highlight) + เงาลึกนุ่มนวล
- ป็อปอัปทุกชนิด (เพย์วอลล์ ยืนยันลบ กรอกข้อมูล ผลเขียนอักษร) ใช้ระบบ **glass popup** กลางจอแบบใหม่
- **คงโทนสี ทอง–แดง–กระดาษ จีนดั้งเดิม** ไว้ทั้งหมด — แก้วถูกย้อมด้วยโทนทอง/แดงของเว็บ
- พื้นหลังอักษรจีนลอย + เมฆพู่กัน + โคมไฟ ยังอยู่ครบเหมือนเดิม

### 🎨 ระบบไอคอน 3D Liquid Glass (แทนอีโมจิทั้งเว็บ)
- ชุดไอคอนวาดเอง **139 สัญลักษณ์ เก็บเป็นไฟล์ SVG จริง** — `assets/icons.svg` (sprite รวม) + `assets/icons/*.svg` (ไฟล์เดี่ยว 139 ไฟล์); เว็บดึงไฟล์ sprite มาใช้เมื่อออนไลน์ และมีสำเนาฝังในตัวเป็น fallback เมื่อเปิดออฟไลน์จาก `file://`
- `ICON('ชื่อ')` คืนค่า `<svg>` inline · `TILE('ชื่อ','red|gold|brown|jade')` คืนค่า**สัญลักษณ์มินิมอล** (วงกลมเรียบสีจาง + ไอคอนเส้นบางสีเดียว — คมชัด อ่านง่ายทุกขนาด)
- สัญลักษณ์ใช้กับจุดสำคัญ: การ์ดเส้นทาง แท็บโหมด เกม ไอคอนพรีเมียม ฯลฯ
- ระบบ **iconize** แปลงอีโมจิที่หลงเหลือใน DOM อัตโนมัติผ่าน MutationObserver — รวมถึงข้อความที่มาจากหลังบ้าน (บทความ หมวดเกม สินค้า ฯลฯ)
- อวตารเปลี่ยนเป็น **อักษรจีนมงคล 24 ตัว** (龍 虎 兔 鹤 梅 兰 月 星 …) ในวงกลมไล่เฉดทอง-แดง

### 👤 ระบบบัญชีผู้ใช้ (อัปเกรด)
- สมัครด้วย **ชื่อ + อีเมล + รหัสผ่าน (SHA-256)** — ตรวจอีเมลซ้ำ, เข้าสู่ระบบด้วยอีเมล/ชื่อ+รหัสผ่าน
- บัญชีเดิมที่ไม่มีรหัสผ่านยังใช้ได้ (เลือกจากรายการในเครื่อง) และตั้งรหัสผ่านเพิ่มได้ที่โปรไฟล์
- สถานะ **พรีเมียม** แสดงในแถบเมนู โปรไฟล์ และหน้ารายการผู้ใช้ของหลังบ้าน

### 👑 ระบบสมาชิกพรีเมียม + การชำระเงิน
- **แพ็กเกจ:** รายเดือน / 6 เดือน / ตลอดชีพ — **แอดมินแก้ราคา/ระยะเวลาได้เอง** (หลังบ้าน → การชำระเงิน)
- **ช่องทางชำระ:** PromptPay (QR สแกนจ่าย + โค้ดคัดลอก) · โอนผ่านธนาคาร (แนบสลิป) · PayPal
- **แจ้งชำระ:** ผู้ใช้กรอกเลข Ref + แนบสลิป → ปรากฏที่หลังบ้านของแอดมิน
- **การยืนยัน (2 วิธี):**
  1. **เครื่องเดียวกับแอดมิน:** แอดมินกด "อนุมัติ" → ปลดล็อกพรีเมียมทันที
  2. **คนละเครื่อง:** แอดมินกด "ออกรหัสปลดล็อก" → ส่งรหัส (WHY-XXXX-XXXX-PLAN) ให้ผู้ใช้กรอกเอง — รหัสผูกกับอีเมลบัญชี ตรวจสอบได้โดยไม่ต้องมีเซิร์ฟเวอร์
- แอดมินปลดล็อก/ยกเลิกพรีเมียมด้วยตนเองได้ (กรณีรับเงินสด) + ดูประวัติรหัสที่ออกทั้งหมด
- เนื้อหาพรีเมียม: **ข้อสอบจำลอง HSK ชุด 2–5 (ทุกระดับ)** และ **เขียนอักษรเกินชุดตัวฟรี** (ชุดที่ 1 ทุกระดับ + พินอิน + อักษรชุดฟรี เปิดให้ใช้ฟรี)

### 📝 ข้อสอบจำลอง HSK (อยู่ในหน้า HSK · แท็บ "ข้อสอบจำลอง")
- **100 ข้อต่อชุด × 5 ชุดต่อระดับ × 6 ระดับ** — ข้อแต่งเอง + ข้อจากคลังเกม + ข้อสร้างอัตโนมัติจากคลังคำศัพท์ (สุ่มแบบ deterministic: ชุดเดิมออกข้อเดิม)
- 3 ส่วนเหมือนสอบจริง: **การฟัง 听力 40 ข้อ** (TTS อ่านข้อความ/คำศัพท์ + เลือกคำตอบ) · **การอ่าน 阅读 40 ข้อ** (เติมคำ/จับคู่/พินอิน/วรรณยุกต์) · **การเขียน 书写 20 ข้อ** (เรียงประโยค/คำ)
- **ชุดที่ 1 ของทุกระดับทดลองฟรี** — ชุด 2–5 เป็นสิทธิ์พรีเมียม (แสดงแม่กุญแจ)
- **จับเวลารายข้อ** (ฟัง 55 วินาที / อื่น ๆ 38 วินาที) · เฉลยทันที · ทบทวนข้อผิด · เกณฑ์ผ่าน 60% · เก็บคะแนนสูงสุดต่อชุด · สะสมแต้ม/XP · ใบรับรองสไตล์ตราประทับ

### 🎵 คอร์สพินอิน (อยู่ในหน้าเริ่มเรียน · แท็บ "คอร์สพินอิน")
- ตาราง **เสียงวรรณยุกต์ 4 เสียง + เสียงเบา** (คลิกฟัง TTS) พร้อม**ตัวอักษรตัวอย่าง** 妈 麻 马 骂 吗 และ**กราฟความถี่เสียง (pitch contour)** แสดงระดับเสียง 5→1 ของแต่ละวรรณยุกต์ (สูงเสมอ / ขึ้น / ตกแล้วขึ้น / ตกลง / เบา)
- **ตารางพินอินเต็ม:** พยัญชนะต้น 23 ตัว + สระ 36 ตัว — พยัญชนะต้นมี**ชื่อเรียกมาตรฐาน**กำกับ (b = bo, p = po, m = mo, zh = zhi, r = ri, …) พร้อมตัวอักษรจีนตัวอย่าง คลิกเพื่อฟังชื่อเรียกมาตรฐาน (b → 玻 bō, zh → 知 zhī)
- **5 บทเรียนแบบฝึก:** แยกเสียงวรรณยุกต์ · พยัญชนะต้น · สระ · การวางเครื่องหมายวรรณยุกต์ · ฟังคำจริงแยกเสียง — เก็บดาว/คะแนนสูงสุดต่อบทเรียน

### ✍️ เขียนอักษรจีน (รวมอยู่ในหน้าอักษรจีน · แท็บ "ลำดับขีด & ฝึกเขียน")
- **เริ่มจากพื้นฐาน:** บทเรียน **8 ขีดหลัก (笔画)** — ขีดนอน ขีดตั้ง เปี๋ย น่า จุด ตวัดขึ้น ขีดหัก ขีดตั้งตวัด — พร้อมตัวอักษรตัวอย่าง ช่องฝึกเขียน และตรวจทิศทาง/รูปร่างให้คะแนน
- **3,000 ตัวอักษร** ครบชุด 通用规范汉字表 一级字表 — ข้อมูลลำดับขีด + เส้นมัธยฐานทุกตัว
- **แอนิเมชันการเขียนขีด** — เส้นโค้งนุ่มลากตาม**ทิศทางการเขียนจริง**ของแต่ละขีด (ซ้าย→ขวา บน→ล่าง ฯลฯ) ตามมาตรฐาน 笔顺规范 กระทรวงศึกษาธิการจีน พร้อม**ลูกศรชี้ปลายขีด ตัวเลขลำดับขีด และสีตามลำดับ** (1 แดง → 2 ม่วง → 3 น้ำเงิน → …) — เล่นอัตโนมัติเมื่อเปิดหน้า ปรับความเร็วได้ เปิด/ปิดลูกศร ตัวเลข และเส้นปากกาได้จากปุ่ม toggle
- **กระดานฝึกเขียน 米字格** ขนาดคงที่ (ไม่ขยับตามจอ/ฟอนต์) พร้อมตัวช่วยลายเส้นตัวอักษรจาง
- **ตรวจให้คะแนน 3 มิติ:** ลำดับขีด · ทิศทาง · ความแม่นยำ — รายงานเป็นรายขีด (เขียว/เหลือง/แดง) + ดาว
- 50 ตัวแรก + ตัวจำเป็นสำหรับผู้เรียน **เรียนฟรี** — ที่เหลือเป็นสิทธิ์พรีเมียม · คะแนน/ดาวบันทึกในบัญชี

## ฟีเจอร์ทั้งหมด (เดิม)

### 🏠 หน้าแรก
Hero + ตัวเลขสถิติ, การ์ดเส้นทางการเรียน (บทความ/พินอิน/HSK/เกม/อักษรจีน/ร้านค้า/พรีเมียม/บัญชี), แถบแผนที่ HSK 1–6, คำศัพท์ประจำวัน (เปลี่ยนทุกวัน), บทความแนะนำ, จุดเด่นของเว็บ และแบนเนอร์ชวนสมัครสมาชิก

### 🧭 หน้าเริ่มเรียน — เส้นทางการเรียน (Roadmap)
- **6 ขั้นตอน** จากศูนย์ถึง HSK 6: พินอิน → อักษรจีน → คำศัพท์ → บทความ → เกม → ข้อสอบจำลอง
- แต่ละขั้นมี**แถบความคืบหน้าของผู้ใช้จริง** (บันทึกอัตโนมัติจากสิ่งที่เรียน) + ปุ่มเข้าเรียน
- **สรุปความชำนาญ** — ระบบประเมินระดับ HSK ปัจจุบันและแสดง**พัฒนาการย้อนหลัง** (เช่น HSK 0 → HSK 1 → HSK 2)

### 📖 บทความ (40 บท)
- หน้าหลักบทความ: เลือกหมวด (11 หมวด) + กรองตามระดับ HSK + ค้นหา
- หน้าอ่าน: แสดง 3 ชั้นพร้อมกัน — **ตัวจีน / พินอิน / คำแปลไทย** + คำศัพท์น่ารู้ + ปุ่มฟังเสียงอ่าน (Web Speech API)
- กด "อ่านจบแล้ว" ได้ **+15 แต้ม +30 XP** และบทที่อ่านแล้วจะมีเครื่องหมาย ✓

### 🎯 HSK 1–6
- หน้าหลัก HSK: แท็บ 6 ระดับ + แสดงระดับที่ระบบประเมินจากความก้าวหน้าของคุณ
- หน้ารายละเอียดแต่ละระดับ: อธิบายว่าระดับนี้คืออะไร + กรองตามหมวด + ค้นหา + ปุ่มทำแบบทดสอบด่วน + **ปุ่มสอบจำลอง**
- คลิกการ์ดคำศัพท์ใดก็ได้เพื่อฟังเสียงอ่าน

### 🎮 เกมภาษา (6 เกม × 6 ด่าน = 36 ด่าน, 288 คำถาม)
| เกม | เนื้อหา |
|---|---|
| เติมคำในช่องว่าง | เลือกคำที่หายไปให้ประโยคสมบูรณ์ |
| จับคู่คำศัพท์ | เห็นคำจีนเลือกความหมายไทย |
| คำนี้อ่านว่าอะไร | เลือกพินอินที่ถูกต้อง |
| วรรณยุกต์จีน | บอกว่าเสียงที่ขีดเส้นใต้เป็นเสียงที่เท่าไร |
| เรียงประโยค | คลิกเรียงคำให้เป็นประโยคที่ถูกต้อง |
| อ่านจับใจความ | อ่านเรื่องสั้นแล้วตอบคำถาม |

- **ด่าน 1 = HSK 1 … ด่าน 6 = HSK 6** ความยากไล่ขึ้นจริง
- ผ่าน 70% = ผ่านด่าน · 90% ขึ้นไป = 3 ดาว · ผ่านด่านแล้วปลดล็อกด่านถัดไป
- ตอบผิดหักหัวใจ (5 ดวง ฟื้นคืนละ 1 ดวงทุก 12 นาที — ปรับได้จากหลังบ้าน)
- จบเกมมีสรุปคะแนน ดาวที่ได้ และ **ทบทวนข้อที่ตอบผิด**

### 🀄 อักษรจีน 3,000 ตัว
ค้นหาได้ 2 โหมด — ตามตัวอักษร/พินอิน/คำอ่าน/ความหมาย หรือ **ตามจำนวนขีด**

## 🌐 การเผยแพร่เว็บขึ้นออนไลน์ (อัปเดต)

### ⚠️ เรื่องที่ต้องรู้ก่อน (สำคัญมาก)
1. ข้อมูลทั้งหมดถูกเก็บใน `localStorage` ของ**เบราว์เซอร์แต่ละเครื่อง** — สิ่งที่แอดมินแก้ในหลังบ้านจะเห็นผลเฉพาะเครื่องตัวเอง จนกว่าจะ "📦 ส่งออกเว็บ" ไปทับ `assets/data/custom.js` แล้วอัปโหลดใหม่
2. **บัญชีผู้ใช้/พรีเมียม/คะแนนสอบ เก็บแยกตามเครื่อง** — ผู้ใช้ login เครื่องใหม่ต้องเริ่มใหม่ (ดูข้อจำกัดใน "ข้อควรปรับปรุง")
3. **ระบบชำระเงินเป็นแบบ manual** — QR/สลิปเป็นของจริง แต่การยืนยันเป็นหน้าที่ของแอดมิน (ไม่มีตัวกลางตัดเงินอัตโนมัติ) กรุณาตรวจสอบยอดก่อนอนุมัติทุกครั้ง

### วิธีที่ 1: Netlify Drop (ง่ายที่สุด)
1. เข้า https://app.netlify.com/drop → ลากโฟลเดอร์ `why-chinese` ทั้งโฟลเดอร์วาง → ได้ลิงก์เว็บสดทันที
2. สมัครบัญชีฟรีเพื่อเก็บเว็บถาวร + เปลี่ยนชื่อลิงก์

### วิธีที่ 2: Cloudflare Pages (ฟรี เร็ว มี CDN — แนะนำสำหรับเว็บนี้)
1. https://dash.cloudflare.com → Workers & Pages → Create → Pages → Upload assets → ลากโฟลเดอร์ `why-chinese` → Deploy
2. ได้ลิงก์ `https://xxx.pages.dev` — CDN ทั่วโลก เร็วสุดในบรรดาฟรีโฮสต์

### วิธีที่ 3/4: Vercel · GitHub Pages
เหมือนเดิม — drag & drop โฟลเดอร์ทั้งโฟลเดอร์

### ⚡ ปรับแต่งเพื่อ SEO (ให้ Google หาเจอ)
1. แก้ `<title>` และ `<meta name="description">` ใน `index.html` ให้มีคำค้นที่คนไทยใช้จริง เช่น "เรียนภาษาจีนออนไลน์ ฟรี HSK พินอิน เขียนอักษรจีน"
2. เพิ่มไฟล์ `sitemap.xml` + `robots.txt` ในโฟลเดอร์ก่อนอัปโหลด (ตัวอย่างท้ายไฟล์นี้)
3. หลัง deploy แล้ว: สมัคร **Google Search Console** → เพิ่ม property → Verify → Submit sitemap → รอ 2–14 วัน
4. สร้าง **Google Business Profile** ฟรี (ถ้ามีหน้าร้าน/สอนออฟไลน์) — ช่วยให้เจอใน Google Maps ด้วย
5. ลงลิงก์เว็บในโซเชียล (Facebook/IG/TikTok/LINE) — ลิงก์ย้อนกลับช่วยแรงก์

### 🔒 HTTPS + โดเมน
ทุกโฮสต์ฟรีให้ HTTPS อัตโนมัติ — ซื้อโดเมนแล้วชี้ CNAME ตามคำแนะนำของโฮสต์ได้เลย

### 💡 ข้อแนะนำ: บัญชีผู้ใช้ข้ามเครื่อง (ถ้าอยากได้จริงจัง)
สถาปัตยกรรมปัจจุบันเป็น **static 100%** — บัญชี/พรีเมียมอยู่ที่เครื่องผู้ใช้ เพื่อให้ login ข้ามเครื่อง + ยืนยันเงินอัตโนมัติ แนะนำต่อยอดด้วย **Supabase (ฟรี)** หรือ **Cloudflare Workers + KV**:
1. `auth` = Supabase Auth (อีเมล+รหัสผ่าน, OAuth Google/Line)
2. ตาราง `users` (progress, premium_until) + `payments` (status, slip, ref)
3. Webhook/Manual: แอดมินยืนยัน → `UPDATE users SET premium_until = ...`
4. เว็บอ่านสถานะผ่าน Supabase JS SDK — โค้ดหลักแทบไม่ต้องเปลี่ยน (ฟังก์ชัน `isPremium()`, `grantPremium()` แค่สลับแหล่งข้อมูล)

## พื้นที่เก็บข้อมูล (สำคัญ)

- **ข้อความ/การตั้งค่า:** เล็กมาก (ธีม ≈ 1 KB, หน้าใหม่ ≈ 2–5 KB)
- **รูปภาพ:** ย่ออัตโนมัติก่อนเก็บ (กว้างสุด 900px) ≈ 30–150 KB/รูป — โควตา localStorage ≈ 5 MB
- **ข้อมูลลำดับขีด:** ฝังในไฟล์ `strokes.js` (~650 KB) — ไม่นับใน localStorage
- ดูปริมาณที่ใช้ได้ที่หลังบ้าน → ภาพรวม

## หมายเหตุทางเทคนิค

- ตัวเว็บเป็น **single page application** ใช้ hash routing (`index.html#hsklevel=3`) เปิดจาก `file://` ได้โดยตรง
- ข้อมูลทั้งหมดโหลดผ่าน `<script>` tag (ไม่ใช้ `fetch`) — ทำงานได้แม้ไม่มีเซิร์ฟเวอร์
- เสียงอ่านใช้ **Web Speech API** (เสียงจีนจะดีที่สุดใน Chrome)
- รหัสผ่านถูกแฮชด้วย **SHA-256** ฝั่งไคลเอนต์ (ไม่เก็บ plain text) — รหัสปลดล็อกพรีเมียมใช้แฮชเดียวกันผูกกับอีเมล
- รูป QR พร้อมเพย์โหลดจาก `api.qrserver.com` เมื่อออนไลน์ — ถ้าโหลดไม่ได้ ระบบแสดงโค้ด EMV ให้คัดลอกแทน
- ข้อมูลผู้ใช้อยู่ใน `localStorage` คีย์ขึ้นต้นด้วย `wszw_` — ลบคีย์เหล่านี้ใน DevTools เพื่อรีเซ็ตทั้งหมด
- เปลี่ยนเวอร์ชัน `?v=` ใน `index.html` เมื่ออัปเดตไฟล์ เพื่อกันแคชเบราว์เซอร์เก่า

## ตัวอย่าง sitemap.xml / robots.txt (สำหรับ SEO)

**robots.txt**
```
User-agent: *
Allow: /
Sitemap: https://โดเมนของคุณ/sitemap.xml
```

**sitemap.xml** (สร้างแล้ววางในโฟลเดอร์เว็บก่อนอัปโหลด)
```xml
<?xml version="1.0" encoding="UTF-8"?>
<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">
  <url><loc>https://โดเมนของคุณ/</loc><changefreq>weekly</changefreq><priority>1.0</priority></url>
  <url><loc>https://โดเมนของคุณ/#learn</loc><priority>0.9</priority></url>
  <url><loc>https://โดเมนของคุณ/#pinyin</loc><priority>0.9</priority></url>
  <url><loc>https://โดเมนของคุณ/#articles</loc><priority>0.8</priority></url>
  <url><loc>https://โดเมนของคุณ/#hsk</loc><priority>0.8</priority></url>
  <url><loc>https://โดเมนของคุณ/#exams</loc><priority>0.8</priority></url>
  <url><loc>https://โดเมนของคุณ/#writing</loc><priority>0.8</priority></url>
  <url><loc>https://โดเมนของคุณ/#premium</loc><priority>0.7</priority></url>
</urlset>
```

> หมายเหตุ: hash route (`#...`) Google จะเห็นเป็นหน้าเดียว — ถ้าอยากให้แต่ละโซนมี URL แยก (SEO แข็งขึ้น) ให้เปลี่ยน router เป็น path-based (Netlify/Cloudflare redirect ไปที่ index.html) — อยู่ในรายการข้อควรปรับปรุง

## ข้อควรปรับปรุงในอนาคต (Known Limitations)

1. **บัญชีข้ามเครื่อง** — ปัจจุบันบัญชี/แต้ม/พรีเมียมเก็บใน localStorage ต่อเครื่อง; ต่อยอดด้วย Supabase (ดูหัวข้อด้านบน) เพื่อซิงก์ข้ามอุปกรณ์
2. **การชำระเงินอัตโนมัติ** — ยังเป็น manual verification (ไม่มี API ตัดเงินจริง); เพิ่มได้ด้วย Stripe Payment Links / PromptPay API ของธนาคาร
3. **รูป QR พร้อมเพย์** — พึ่ง API ภายนอกเมื่อออนไลน์; ฝังตัวสร้าง QR ในเครื่องได้เพื่อความออฟไลน์สมบูรณ์
4. **เสียงฟังข้อสอบ** — ใช้ TTS ของเบราว์เซอร์ (ต่างจากเสียงคนจริงในสนามสอบ); อัปโหลดไฟล์เสียง mp3 ได้ในอนาคต
5. **คลังลำดับขีด** — มี 440 ตัวที่ใช้บ่อยที่สุด; ขยายเป็น 3,500 ตัว (一级字表 เต็ม) ได้ด้วยการดาวน์โหลดข้อมูลเพิ่ม (~5 MB)
6. **SEO แบบลึก** — hash route ทำให้ Google เห็นหน้าเดียว; เปลี่ยนเป็น path router เพื่อแรงก์รายหน้า
7. **ข้อสอบเพิ่ม** — แต่ละชุดสร้างจากคลังข้อแต่งเอง + คลังเกม + คำศัพท์อัตโนมัติ (deterministic); เพิ่มข้อแต่งเองใน `assets/data/tests.js` ได้ไม่จำกัด (ระบบสุ่มและเฉลยให้เอง)
